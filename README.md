# coin-chart

Binance 공개 시세(USDT 마켓)를 실시간으로 보여주는 코인 차트 페이지.

- 주소: https://gwlimcpa-cmd.github.io/coin-chart/
- 캔들차트, 이동평균, 볼린저밴드, RSI, MACD, 거래량
- 그리기 도구(추세선, 수평선, 수직선, 사각형, 피보나치)
- 관심종목, 가격 알림(페이지가 열려 있는 동안 작동)
- 전략 백테스트(이동평균 교차, RSI, 볼린저밴드, MACD)

시세는 Binance 공개 시장 데이터(data-api.binance.vision)를 사용하며, 연결에 실패하면 가상 시세로 표시됨. 투자 판단의 근거로 쓰기 전에 거래소 화면과 대조할 것.
